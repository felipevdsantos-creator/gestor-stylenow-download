# Gestor de Pedidos Stylenow — programa para computador

Instaladores do **Gestor de Pedidos Stylenow** para Windows e Mac. É o mesmo
Gestor do navegador, com a mesma conta, instalado como programa:

- **imprime a comanda sozinho** quando o pedido é aceito, sem abrir a janela de impressão;
- **o aviso de pedido novo sempre toca**, mesmo que ninguém tenha clicado na tela;
- **abre junto com o computador** e continua ligado perto do relógio.

## Baixar

- **Windows:** [Instalar-Gestor-Stylenow-Windows.exe](https://github.com/felipevdsantos-creator/gestor-stylenow-download/releases/latest/download/Instalar-Gestor-Stylenow-Windows.exe)
- **Mac:** [Instalar-Gestor-Stylenow-Mac.dmg](https://github.com/felipevdsantos-creator/gestor-stylenow-download/releases/latest/download/Instalar-Gestor-Stylenow-Mac.dmg)

O jeito mais fácil é pelo próprio Gestor: na tela de entrada ou no topo do
quadro de pedidos, clique em **Baixar para computador**.

## Na primeira vez

**Windows:** se o navegador perguntar sobre o arquivo, clique em **Manter**.
Se aparecer "O Windows protegeu o computador", clique em **Mais informações**
e depois em **Executar assim mesmo**.

**Mac:** arraste o Gestor para a pasta **Aplicativos**. Se o Mac não deixar
abrir, vá em **Ajustes do Sistema → Privacidade e Segurança** e clique em
**Abrir Mesmo Assim**.

Depois, é só entrar com o mesmo e-mail e senha de sempre.
